# Abnormal

An email service: mailboxes on our domains or yours, webmail, desktop and mobile clients, a management API and a CLI, run on [Stalwart](https://stalw.art/) and Cloudflare Workers.

- **Website and shop**: <https://abnormalhq.com>
- **Webmail**: <https://webmail.abnormalhq.com>
- **Developer documentation**: <https://developers.abnormalhq.com>
- **Service status**: <https://status.abnormalhq.com>

## Repositories

| Repository                                                       | What it is                                                                                                   |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| [abnormalhq](https://github.com/abnormalhq/abnormalhq)           | The bilingual website and storefront: plans and prices, shop, redeem page, buyer account and guide.          |
| [mail](https://github.com/abnormalhq/mail)                       | mailhq: the admin console, webmail and developer site, plus the desktop and mobile clients, CLI and SDK.     |
| [status](https://github.com/abnormalhq/status)                   | The public status page, a separate Worker that stays up when the service does not.                           |
| [ui](https://github.com/abnormalhq/ui)                           | The shadcn registry behind the website and mail: design tokens, base components and brand pieces.            |
| [homebrew-tap](https://github.com/abnormalhq/homebrew-tap)       | Homebrew casks and formulae for Abnormal Mail and the `abnormal` CLI.                                        |
| [doppel](https://github.com/abnormalhq/doppel)                   | A desktop client that gives AI agents real, persistent browsers.                                             |

# abnormalhq/.github

Organization-wide defaults for [abnormalhq](https://github.com/abnormalhq).

| Path                                                           | What it does                                                                                    |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [`profile/README.md`](profile/README.md)                       | The organization's profile page on GitHub (shown only while this repository is public).         |
| [`CONTRIBUTING.md`](CONTRIBUTING.md)                           | How to propose a change: branches, checks, Conventional Commits.                                |
| [`SECURITY.md`](SECURITY.md)                                   | How to report a vulnerability privately.                                                        |
| [`SUPPORT.md`](SUPPORT.md)                                     | Where to get help with a mailbox, an order or the service.                                      |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE)                            | Default issue forms (bug report, feature request) and the links shown when an issue is opened.  |
| [`pull_request_template.md`](pull_request_template.md)         | The default pull request description.                                                           |

GitHub uses a file here only for a repository that has no file of the same kind of its own (in its root, `docs/` or `.github/`). A repository that needs something different adds its own copy, which replaces this one for that repository only; issue templates are replaced as a whole folder, not form by form.
